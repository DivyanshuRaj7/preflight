# MCP Policy

## Required
None.

## Optional
- GitHub MCP: useful for repository/issue/PR workflows when connected.
- Documentation MCP (for example Context7): use only when current library/API documentation is actually needed.
- Playwright MCP: not required for the MVP; the project's Playwright code is the reproducible deliverable.

Keep MCPs disabled unless they remove a real bottleneck. More tools consume model context and can increase agent confusion.
